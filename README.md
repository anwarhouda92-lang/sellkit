# SellKit v0.1

MVP for a multilingual e-commerce tools platform.

## Included
- Pricing calculator
- ROAS calculator
- Profit calculator
- Product description generator (MVP/local draft)
- Ad generator (MVP/local draft)

## Run locally
```bash
npm install
npm run dev
```

Then open http://localhost:3000
